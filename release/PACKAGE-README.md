# Enterprise Workflow

Reusable workflow framework for .NET 10: durable execution, typed business state,
fluent authoring SDK, forms, authorization, audit, media and turnaround reports.

The framework supports SQLite and an Oracle adapter. Compatibility must be checked
against the release evidence for the selected operating system and provider.

The `EnterpriseWorkflow.Cli` package provides the `ew` .NET tool.
`EnterpriseWorkflow.Templates` provides `ew-module` and `ew-embedded` templates.

Source, installation instructions and release evidence:
https://github.com/mbo2olivier/enterprise-workflow

Candidate artifacts are for qualification. Public availability is established only
by a published release and its NuGet.org consumption evidence.
