## Publication restante pour clôturer L10b

Le workflow est livré localement, pas exécuté à distance par cette itération. Aucune URL Pages effectivement déployée n’est revendiquée. Le dépôt est encore sur son checkout de travail, sans commit/push de ces changements par l’agent.

1. Intégrer ces changements sur `main` par le circuit de revue du dépôt.
2. Dans GitHub, choisir **Settings → Pages → Build and deployment → Source: GitHub Actions** si ce n’est pas déjà configuré.
3. Laisser le workflow `documentation` réussir (ou le déclencher manuellement sur `main`) : build, recette publique et job `deploy`.
4. Ouvrir `https://mbo2olivier.github.io/enterprise-workflow/`, vérifier accueil, tutoriel LeaveRequest, recherche et ressources, puis consigner URL du run et résultat avant de déclarer L10b clos.

Le domaine personnalisé n’est pas configuré. Le déploiement ne requiert pas le plugin d’hébergement Sites : l’architecture validée utilise GitHub Pages.
