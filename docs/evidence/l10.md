### Contrôle final de cette itération

- Les deux archives finales macOS ARM64 (avec notices NuGet et .NET) sont dans
  `/tmp/ew-l10-final-framework-dependent` et `/tmp/ew-l10-final-self-contained` ;
  construction, extraction et recette de restauration intégrale réussies.
- Tests CLI .NET : 6 au total, 5 réussis, 1 ignoré (test de cycle long optionnel) ;
  le cycle `ew dev` a été exécuté séparément dans la recette en cache neuf.
- `publish-release.py` refuse explicitement les artefacts issus d’un checkout
  modifié ; les builds locaux restent donc des candidats de test non publiables.
  La CI construit les artefacts publiables depuis le commit taggé propre.
