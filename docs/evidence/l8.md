# Preuve du lot L8

Date : 7 octobre 2026.

## Périmètre livré

- contrats de présentation et catalogue de processus/formulaires versionnés ;
- Razor Class Library `EnterpriseWorkflow.Web` et Host `EnterpriseWorkflow.Kernel` ;
- parcours métier issu du prototype : connexion, Today, catalogue, démarrage, candidats habilités, inbox, détail, claim/release/complétion et demandes ;
- composant Razor personnalisé alimenté par une projection autorisée, sans exposition de l'état brut ;
- administration des profils, comptes locaux, associations, mappings de groupes et habilitations workflow/nœud/action ;
- réglages de présentation persistés et audités, paramètres runtime sensibles en lecture seule ;
- support SQLite et Oracle, mode de migration `Validate|Apply`, authentification locale ou LDAP configurée ;
- tests de services, de persistance, de composants web et smoke Playwright Linux.

Le dossier `prototype/` a servi de référence fonctionnelle et visuelle. Le produit reste Razor/Blazor et n'embarque ni React/Vite ni les données simulées du prototype.

- compilation locale complète `Release` : réussie, sans avertissement ni erreur ;

- suite complète de la solution : succès confirmé par le porteur ;
- smoke Playwright Linux : succès confirmé après correction de la route de mutation des réglages ;
- suite Oracle Enterprise 19.19 sur le schéma jetable `EWTEST` : succès confirmé avec credentials locaux synchronisés par la stack Compose ;
- matrice GitHub Actions : succès confirmé par le porteur.

Le retour de qualification du 7 octobre 2026 est : `OK solution / Playwright Linux / Oracle 19.19 / GitHub Actions`. Les quatre axes requis par [la procédure L8](../l8-validation.md) sont acquis ; L8 est terminé et qualifié.

## Limites

- L8 ne livre pas le packaging, la CLI ou les templates de L9 ;
- l'interface ne permet pas de modifier une définition publiée ni les paramètres runtime sensibles ;
- Playwright n'est volontairement exécuté que sur Linux ;
- aucune qualification Active Directory n'est revendiquée.
