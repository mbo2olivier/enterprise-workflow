# Preuve du lot L2

Date : 1er octobre 2026. Commit : changements de travail non encore commités au moment de cette preuve.

## Livrables exécutés

- modèle canonique immuable avec identifiants ordinaux sensibles à la casse, versions de définition et de schéma distinctes ;
- nœuds Start, Service, Decision et End, références nommées/versionnées d’exécuteurs et d’évaluateurs ;
- catalogue de types extensible et validation de configuration fournie par l’application ;
- brouillon inspectable, diagnostics stables/localisés et statut publiable explicite ;
- validation des doublons, références absentes, cycles, nœuds inatteignables, chemins sans fin, sorties manquantes et branches ambiguës ;
- JSON objet immuable, sans doublons/commentaires, profondeur et tailles bornées, propriétés triées et nombres réémis sans conversion avec perte ;
- sérialisation canonique schéma 1 et empreinte SHA-256, indépendante de l’ordre d’insertion ;
- limites configurables de définition, nombre de nœuds, état et configuration ;
- projet `EnterpriseWorkflow.Persistence.Abstractions` sans EF ni provider, avec opérations atomiques et résultats structurés ;
- règles pures pour publication/déduplication, UTC milliseconde, transitions d’instance et fencing token + génération + expiration ;
- exemple C# de demande de congé à décision exclusive.

## Commandes et résultats locaux

Environnement : macOS 26.3 ARM64, SDK .NET `10.0.102`, runtime .NET `10.0.2`.

```bash
dotnet restore EnterpriseWorkflow.slnx --locked-mode
dotnet build EnterpriseWorkflow.slnx --configuration Release --no-restore --disable-build-servers --maxcpucount:1
dotnet test --solution EnterpriseWorkflow.slnx --configuration Release --no-build --no-restore --max-parallel-test-modules 1
dotnet run --project samples/MinimalWorkflow/MinimalWorkflow.csproj --configuration Release --no-build --no-restore
```

Résultats : build réussi avec zéro avertissement et zéro erreur ; 42 tests réussis, 0 échec, 0 ignoré. L’exemple construit 6 nœuds et produit l’empreinte `bb13332e1dbd781a445f83f3326ff9f2d1a3c25098ed07664416a1cd27ac6d07`.

## Preuves acquises et limites

T01 et T02 sont acquis pour le modèle L2. T18 couvre désormais les quatre projets de production et vérifie l’absence de packages externes dans ces projets.

Les règles du store sont des preuves pures de contrat, pas des preuves de transaction, verrouillage ou durabilité. Aucun adaptateur SQLite/Oracle, mapping, migration, worker, tâche humaine, timer ou livraison outbox n’est livré. Ces preuves restent réservées à L3 et aux lots fonctionnels correspondants. L’API de persistance reste révisable jusqu’aux prototypes des deux providers, conformément à l’ADR 0013.
