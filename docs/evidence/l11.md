# L11 — preuve d’implémentation et qualification

Date : 18 novembre 2026. Statut : implémentation et qualification en cours ; aucune clôture ni publication revendiquée. La série L10 reste close. Références : [plan](../l11-hosting-security-localization-plan.md), [spécification](../l11-spec.md), [ADR 0029](../adr/0029-composition-hotes-et-capacites-l11.md).

## Livrables présents

- Package source `EnterpriseWorkflow.Hosting`, builders web/non-web et kernel standard composé sur ce socle ; points de configuration modules/handlers/runtime/présentation/DI et exemple `CustomKernel`.
- Contrats optionnels d’identité, import, maker/checker et second facteur ; adaptation des annuaires, admission locale sur sessions et autorisations, administration conditionnelle et contrôles serveur.
- Écran générique de seconde preuve, cookie temporaire protégé, annulation, aucune session avant validation ; assurance persistée pour obliger les anciennes sessions simples à se reconnecter lorsque le second facteur est activé.
- `.env` propre à `ew dev`, priorités et séparation entre secrets hôte et processus de compilation ; identités JSON inchangées.
- Langues d’instance, ressources du socle, préférence utilisateur locale persistée, textes métier structurés et projections par culture ; sample LeaveRequest bilingue 1.9.0 / révision 10, schéma d’état 4 conservé car la forme des données métier reste identique. Les anciens artefacts et définitions ne sont pas réécrits.
- Migrations additives SQLite/Oracle pour préférences et assurance des sessions ; tests hors ligne du SQL Oracle 19, sans prétendre exécuter Oracle.

Les commandes et résultats finaux sont ajoutés après les vérifications de l’itération. La qualification Oracle réelle, la matrice des trois OS et la validation bancaire restent distinctes. Les nouveaux guides wiki signalent explicitement que les API L11 ne sont pas dans les packages déjà publiés. Le catalogue de packages inclut le nouveau SDK d’hébergement ; aucune publication NuGet n’est effectuée par cette implémentation.
