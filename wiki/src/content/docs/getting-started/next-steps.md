If you have completed the first tutorial, you have deployed an SDK-built module to the precompiled Windows Kernel and exercised its definition, state and permission contracts.

- Read [the development cycle](../../basics/development-cycle/) to work with named environments and retained generations.
- Read [typed state](../../core-concepts/state/) before adding fields or custom validation.
- Follow [LeaveRequest](../../examples/leave-request/) to combine requester confirmation with manager selection, manager approval and a final HR pool review.
- Use [handlers and services](../../guides/handlers/) when adding business logic or external integration.
- Review [Kernel installation](../../operations/install/) when preparing another environment or a managed deployment.

A successful development run does not define your production topology. Choose the database, identity provider, private media storage and operational backup procedure for your installation. The [compatibility matrix](../../reference/compatibility/) describes the boundaries of the release.
