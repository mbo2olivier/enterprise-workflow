## Try the failure paths

- Submit a two-character reason: validation must reject it.
- Try to review as Alice: her seed grants no review permission.
- Stop the policy API before approving: the service must not report a fabricated successful HTTP response. Inspect failure/retry diagnostics, restart the API, then observe recovery according to runtime policy.
- Introduce a C# error in the disposable generated project: the previous valid development generation remains available. Correct the error before packaging.

This HTTP example reads a policy. For remote **writes**, define receiver-side idempotency before using the same approach; a crash after remote success can repeat the call. See [service integration](../../examples/service-integration/).
