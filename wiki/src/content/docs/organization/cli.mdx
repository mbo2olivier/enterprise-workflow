## Install and generate from local packages

The repository supplies a local-feed helper so this tutorial does not depend on an unpublished package. It builds the framework and example platform, installs the tool into the disposable workspace, and keeps its NuGet cache separate.

```sh
export EW_ORG_ROOT="$(mktemp -d -t ew-org.XXXXXX)"
export EW_ORG_ROOT="$(python3 -c 'import os,sys; print(os.path.realpath(sys.argv[1]))' "$EW_ORG_ROOT")"
python3 scripts/qualify-l12.py packages "$EW_ORG_ROOT"
python3 scripts/qualify-l12.py generate "$EW_ORG_ROOT"
"$EW_ORG_ROOT/tools/few-example" distribution
```

**Expected:** the last command prints `Example.Workflow 1.0.0-rc.1`. `Generated/` contains a module derived from `ExampleWorkflowModule`, an exact SDK package reference and `ew.dev.json`. Keep `EW_ORG_ROOT` in this terminal for the next chapters. On Windows the installed tool has an `.exe` suffix.

The `generate` helper deliberately checks that generation fails before setup, then runs setup and new. When using your own published tool, the developer sequence is:

```sh
few-example setup
few-example new few-example-module -n MyWorkflow
```

Run this manual sequence in a **separate empty directory**, not over the helper’s `Generated` project. Template setup is explicit; `new` does not silently install missing templates.

## What changes for your organization

Replace the command name, package IDs, template identity/short name and SDK reference together. Publish your SDK, contracts and templates to your private feed, and use ordinary NuGet credential mechanisms. Never embed feed passwords in generated projects.

| Failure | Recovery |
| --- | --- |
| Missing template | Run the tool’s `setup` command in the intended environment |
| Local package hash mismatch | Use the helper’s isolated NuGet configuration; do not delete the lockfile to bypass it |
| Tool still behaves like an old build | Repack and reinstall the tool; rebuilding source does not replace an installed tool |
| CLI has services but kernel does not | Use the shared `Hosting` composition in both entry points |
